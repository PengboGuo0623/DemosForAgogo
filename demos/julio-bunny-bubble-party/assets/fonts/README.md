# Font Sources and Licenses

These fonts are self-hosted so the Android WebView demo does not depend on a
runtime connection to Google Fonts.

## Fredoka Variable

- Runtime file: `fredoka/Fredoka-Variable.ttf`
- Family use: playful display headings, rewards, and short high-emphasis copy
- Axes: width 75–125; weight 300–700
- Designers: Milena Brandão, Hafontia
- Official Google Fonts source:
  <https://github.com/google/fonts/tree/main/ofl/fredoka>
- Downloaded file:
  <https://raw.githubusercontent.com/google/fonts/main/ofl/fredoka/Fredoka%5Bwdth%2Cwght%5D.ttf>
- Retrieved: 2026-08-14
- SHA-256: `2ba02e68b152868aef9ba28e24b3648c7d457fe6f25c761f2c2c53fb61a73fc8`
- License: SIL Open Font License 1.1; preserved at `fredoka/OFL.txt`

## Nunito Variable

- Designers: Vernon Adams, Cyreal, Jacques Le Bailly

  <https://github.com/google/fonts/tree/main/ofl/nunito>

# Julio Bunny: Bubble Splash Adventure

A landscape preschool H5 vertical slice built from original Julio Bunny FLA scene assets.

## Demo Entry

- `index.html`: static GitHub Pages entry.
- `assets/`: production JavaScript, CSS, self-hosted fonts, atlases, scene art, and interaction bubble art.
- `preview.jpg`: gallery card preview.

## Current Scope

- Fixed `1280 x 720` landscape design canvas with responsive fit.
- Original FLA background, foreground, Julio, fish, and bubble artwork.
- Intro animation followed by a gentle 1, 2, and 3 bubble drag progression.
- Early animated drag guidance, soft error return, immediate visual feedback, completion celebration, and replay.
- English immersive UI with self-hosted Fredoka and Nunito fonts.
- No runtime network dependency, music, sound effects, App SDK, login, tracking, or backend.

## Build Provenance

This folder contains the verified production output only. Source and FLA processing evidence remain in the working project used to produce the demo.
